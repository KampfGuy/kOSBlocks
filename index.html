Quick guide
    

  1. Drag blocks from the left (Flight, Telemetry, Logic…) or grab a ready-made Template.
    2. 

  2. Watch the kerboscript appear live. Switch to Code to see it highlighted & linted.
    3. 

  3. Simulate / Python: runs your script in a built-in kerboscript interpreter with 2D Kerbin physics – see terminal output, charts, trajectory and outcome before flying. Write Python with sim.run() / sim.sweep("turnEnd",[30000,45000,60000]) to tune.
    4. 

  4. Use Tune to tweak numbers, or Python for KSP math (Δv, TWR, Hohmann…) and to rewrite values with kos.set_var("targetAlt", 90000).
    5. 

  5. Click Export .ks. Put the file into Kerbal Space Program/Ships/Script/ (the Archive, volume 0).
    6. 

  6. In game, open the kOS terminal on your vessel: SWITCH TO 0. then RUNPATH("boot_launch"). (or RUNPATH("0:/boot_launch.ks").).
    7. 

  7. Boot scripts: put the file in Ships/Script/boot/ and choose it as the boot file in the VAB part menu of the kOS CPU.


Tips
  • Every statement ends with a period .; blocks use { }.
    • 

  • LOCK re-evaluates every tick; SET evaluates once.
    • 

  • Always end launches with UNLOCK STEERING. UNLOCK THROTTLE. and set SHIP:CONTROL:PILOTMAINTHROTTLE TO 0.
    • 

  • "Edit code myself" lets you type freely; switching back to blocks regenerates code from blocks and discards text edits.
    • 

  • Projects are saved in your browser's localStorage.
