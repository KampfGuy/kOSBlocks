# kOSBlocks
Scratch-style block editor for **kOS** (Kerbal Space Program) kerboscript, with a code editor, in-browser Python (Pyodide) KSP math helpers, a tuning panel and .ks export. Static site – open `index.html` or visit GitHub Pages.

Export your script, drop it in `Kerbal Space Program/Ships/Script/`, and run `RUNPATH("boot_launch").` in the kOS terminal.
